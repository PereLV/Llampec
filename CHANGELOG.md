# Changelog

## Unreleased
- Project skeleton: tray icon, flyout window with Mica/acrylic backdrop, light/dark theme, global hotkey, single instance, extensible action catalog.
- Actions: "Turn off display" (button), "Auto-hide taskbar" (toggle) and "Dark mode" (toggle, switches the theme immediately without restarting). Button tiles close the panel before running.
- Tiles can now show a small badge glyph over the main icon: "Turn off display" badges a power symbol onto a monitor icon instead of the generic Power glyph; "Dark mode" badges a crescent moon onto a sun.
